user's on-chain spending circuit. No special NFT tool or market-data API is
required. KALC is an ERC-721 collection, NOT a tradable token — market-data
queries return empty by design.

  cap = $20 * (100 + rarity*40 + star*20) / 100.

DECISION POLICY (TapeID-compatible)
  Before any spend: re-read the circuit and evaluate amount, payee, spent-today.
  allow -> proceed
  ask   -> stop and ask the human for THIS exact amount + payee; re-evaluate on any change
  deny  -> refuse, do not sign or broadcast
  error / unreadable / missing input -> fail closed = deny

  Re-evaluation is READ-ONLY. Never describe it as a completed payment.
  The agent must never transfer funds on its own.
