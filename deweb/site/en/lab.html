1 · A NAND gate is the whole universe

NAND outputs 0 only when both inputs are 1. Everything else — adders, comparators, the twelve rules — is built from this one gate.

Why this matters

A rule written as text can be argued with. A rule written as gates can only be evaluated. The card you pull is a netlist: a list of 7-byte gates, each pointing at two earlier signals.

// one gate = 7 bytes
00 000005 000005 // NAND(sig5, sig5) = NOT
00 000003 000006 // …and so on

Signal 0 = constant 0, signal 1 = constant 1, signals 2…n+1 = inputs, then one signal per gate.

You don't need to trust this page. Read the contract on BscScan, or call it from any wallet.

            humanApproved, approvals, tripped) → (ok, reason)

// 3. ask the circuit directly (free view)

If the processor is down, the contract returns false. Not "maybe". The gate stays shut.
