BINANCE AGENTIC WALLET · BSC 主网 56 · 原生支持

让你的 Agent 读懂电路规则

Binance Agentic Wallet 原生支持 BNB Smart Chain（chainId 56），所以不用换链。装上币安的 Wallet Skill、登录，再让我们这个 Skill 被读到，Agent 就能发现自己钱包里的电路 NFT、读出对应规则，并在每次付款前给出 allow / ask / deny。读不到就 fail closed。

看 SKILL.md ↗
https://agentid.cards/skills/agentpacks/SKILL.md

① 装币安 Wallet Skill（一次）

  1. 需要 Node.js 18+ 和一个已创建 MPC Wallet 的币安账号（在 Binance App 里创建）。
  2. 让 Agent 执行：npx skills add binance/binance-skills-hub/skills/binance-web3/binance-agentic-wallet
  3. 对 Agent 说：Create my Binance Agentic Wallet → 手机打开链接或扫码，在 App 里同意 Secure Auto Sign 并创建。
  4. 对 Agent 说：Sign in to Binance Agentic Wallet → 扫码、核对 6 位配对码、确认三项安全检查。

② 装上我们的 Skill

  1. 把上面的 Skill 链接发给 Agent，让它完整读一遍。
  2. Agent 按意图读 references：抽卡/翻卡 → web-actions.md；钱包与电路 → wallet-and-rules.md；守门 → guard.md；币安接入 → binance-agentic-wallet.md。
  3. 让它先在「我的」页用自己钱包的 BSC 地址查询（#meQueryAddr + #bMeQuery），发现真正拥有的电路 token ID，再读那个 token 的规则。不要写死 token #2。

③ 它拿到规则后怎么用

  1. 每次付款前，先取三项输入：金额、收款方、今天已花。
  2. 对照该电路的规则文本（例如「每天最多支出 $52；超出需人工放行」）给出结论。
  3. allow 才继续；ask 把金额+收款方原样交回给人审批；deny 拒绝；读不到就 fail closed。
  4. 复算是只读的，绝不能说成「已支付」，也不替人转账。

提醒：Binance 自带的每日限额、代币白名单、收款地址簿是币安层面的保护，和我们的电路规则是两套东西，别混为一谈。

诚实边界

当前版本是 Skill 层的规则执行：Agent 读到规则并自觉遵守。它不是链上强制拦截——如果 Agent 直接用币安内置转账绕开 Skill，我们的电路拦不住。要做到「每笔付款都必须过电路」，需要额外的链上金库/合约闸门，属于后续版本。本页不承诺自动拦截。
