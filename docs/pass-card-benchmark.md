## 我们直接采纳的三个机制

1. **限量创世 Pass**：我们已有「百连 · 创世（第 1 季起停售）」——进一步做成独立
   **限量 Pass 档**：总量固定（建议 1,000 或 3,333）、固定单包价、限时窗口、
   无白名单。Pass = 免费包产量翻倍 + 守门人高阶局解锁 + 靓号卡池优先
2. **持有产出**：EmberWorld 的金币 ≈ 我们的积分（兑 SR）+ 免费包；Pass 持有者
   每日产出加成，给"拿着不动"的人发工资
3. **电路队友**：EmberWorld 里 FabX 电路是战术大脑；我们同构——电路卡穿在
   Agent ID 上就是它的支出规则。生态叙事完全互认

## 不抄的部分

- 动作 RPG 玩法本身（我们是卡牌 + 守门人，不做实时战斗）
- 金币经济（无 token 发行是红线；产出用「包 + 积分」闭环）

## 一句话

EmberWorld 证明了 TapeOut 电路生态的**消费层**能跑通：Pass 限量 → 公平发射 →
持有产出 → 电路进玩法。我们把它换成卡牌形态：**Pass = 创世包，电路 = 卡魂，
产出 = 包与积分**。pitch 里可以并列引用，证明赛道有伴。
