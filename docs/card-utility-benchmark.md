# 卡牌用途对标研究 · 抽到名卡之后能干嘛

> 研究动机：决定 Agent Packs 留存的不是抽卡爽感，是**抽到之后的出口数量**。
> 结论：活得久的卡牌游戏名卡都有 5+ 个出口；Agent Packs 设计 7 个，其中「穿」与「租」构成独有的**行为租赁**新品类。

---

## 1. 对标现状（2026-11 检索）

### 宝可梦 TCG Pocket（2 年，2 亿+下载，月活峰值 3900 万）
- **打**：20 张卡组、分钟级对战，卡是构筑材料
- **秀**：皇冠/沉浸式稀有度 = 社交地位；皇冠卡不可交易（官方刻意保稀缺）
- **养**：重复卡熔成 Flair / 交易代币
- **卖**：受限交易系统（同稀有度互换、耗体力与 Shinedust）
- **兜底**：Pack Points 攒分换指定卡——"保底"被证明是留存必需品
- 教训：DeNA 财报 MAU 从 3900 万跌到 2300 万——**单靠收集爽感必然衰减，必须不断给出口**

### Splinterlands（7 年，日均 6200 DAU、单新卡包卖 400 万美元）
- **打**：排位/公会战；**租**：卡片出租收 DEC——被动收入是长青核心；**卖**：内置市场；**养**：重复卡合成升级；**质押**：卡上土地/Conflict
- 官方口号即产品哲学："YOU OWN YOUR CARDS, NOT US"
- 教训：**出口越硬（能下蛋），生命周期越长**

### Gods Unchained（Immutable zkEVM）
- 重复卡熔合成更高品质（通缩机制）；共享订单簿免 gas 交易；**Pythia's Deckbox：USDC 按天租赁、链上托管、自动归还**——租赁被验证为可独立成业务

### CT 卡包（我们的对标样本，已验证币圈人群爽点）
- **打**：自走棋（何一卡「连环爆仓」、Elon「拉盘」——名人梗=技能）；**秀**：卡池里抽到自己；**养**：升星赌运；**卖**：换 CT 点（不可提现，合规边界示范）；**特权**：SSR 带技能进赌场；**认领**：KOL 认证自己的卡

## 2. Agent Packs 的七个出口（设计定稿）

| # | 出口 | 机制 | 稀缺度错配 |
|---|---|---|---|
| ① | **打** | 名人的性格=战术：CZ 卡「钻石手」（连跌不卖）、Elon 卡「Pump」（波动加仓）——技能即人设 | 全稀有度可上阵 |
| ② | **穿**（独有） | `equip()` 到自己 .ai：你的 AI 按**名人同款规则电路**行事 | SSR+ 可穿 |
| ③ | **秀** | 卡面=真实 .ai 名字；晒卡=晒关系；「我抽到你了」UGC | 全稀有度 |
| ④ | **养** | 攒重复升星；**星级强化规则本身**（3 星 CZ=钻石手+抄底） | 重复卡有兜底出口 |
| ⑤ | **卖** | SSR+ = TapeOut Circuit NFT，二级市场流通 | SSR+ 可交易 |
| ⑥ | **租**（独有组合） | **行为租赁**：把卡的规则电路按天借给别人的 AI——租的是性格不是图片 | SSR+ 可出租 |
| ⑦ | **特权** | SSR+ 进特殊赛季模式/赛事（赌场类后置评估） | SSR+ |

**Pack Points 式兜底必须抄**：攒分开包积分换指定卡——宝可梦验证过的"防弃坑安全网"。

## 3. 「行为租赁」—— 别人抄不走的那一个

```
Splinterlands 出租：一张图片卡 → 对方上阵用
Agent Packs 出租：一段规则电路 → 对方的 AI 性格临时变成你这张卡
                   （7 天里，他的钱包 AI 按「钻石手」行事）
```

- 技术底座：tapeid.xyz 的规则电路模型（名字+电路一笔原子铸造）
- 经济意义：名卡成为**能下蛋的资产**（Splinterlands 7 年验证的模型），但下的蛋是"行为"
- 风险提示：租赁是市场行为，页面**不承诺任何收益率**；收益由租价与需求决定

## 4. 稀有短 ID 卡：授权与价值设计（关键边界）

> 问题：`ab.ai` 属于在 Binance 认领它的人（不可转让）。**我们没有这个 ID 的所有权**——那卡能给人什么好处？
> 答案三原则：**卡 ≠ 身份**。价值只来自——官方注册表可数的稀缺、系统内效用、正主自愿参与；绝不来自也不赋予身份权利。

### 机制定稿

- **认领制卡池（opt-in）**：`claimIntoPool()` 自愿入池——正主不上桌，卡不存在；纠纷从源头消灭。认领 = 一笔 .ai 交互，本身就是增长引擎（每个持 .ai 用户都有理由打这笔）
- **版税飞轮**：本尊认领后该卡亮 VERIFIED 徽章；后续交易/租赁按 % 分账本尊 → 正主有经济动力认领 → 持卡人坐享"激活增值"（CT Packs 的 KOL 认领徽章已验证该飞轮）
- **稀缺不掺水**：卡档位挂钩官方 ERC-721 注册表的真实稀缺度（两位数 ID 全网限量；黑客松获奖项目也只是"获赠领取资格"）——稀有度可数，不是运营拍脑袋
- **系统效用**：短 ID 卡自带"创始电路"技能组 + 七出口全开（打/穿/秀/养/卖/租/特权）——好处全部来自系统
- **隐私边界（红线 9）**：卡面只有名字与卡艺；不显示钱包地址、不显示资产、不提供按名查钱包
- **退出 = 绝版**：随时可下架；已流通卡停发新版进入"绝版"状态——比删除更利于收藏
- **页脚声明模板**：卡为纪念物与游戏资产，与该 Agent ID 的权利归属无关

## 5. 落地排期

- **Season 0（黑客松 MVP）**：①打 ③秀 ④养 + Pack Points 兜底——四个出口先把留存跑通
- **Season 1**：②穿（equip 与 tapeid 电路互通）、⑤卖（NFT 二级市场）
- **Season 2**：⑥租（托管合约+按天计费+自动归还，参考 Pythia's Deckbox 模式）、⑦特权模式

> 纪律提醒：出口越多越好，但**黑客松 18 天内只做四个**——先活下来，再下蛋。
