
## 3. 定价纪律（守住这条，模式才转得动）

- **单次流片 ≤ $1**：玩家无感区间，像买皮肤不像买保险
- 单包 0.002 BNB 不动（对标 CT Packs 心智）
- 稀有度/星级决定**参数档位上限**，玩家流片后在档位内自由调数值（已实现演示档）
- 电路字节无限供应 = **无所谓**：同字节谁都能再流片，但价值锚在**卡**
  （稀有度 / 星级 / 绝版 / 正主身份），不在字节独占——与 CT Packs 同理

## 4. 防女巫（经济学成立的前提）

- 免费包 1/天/**KYC 身份**（Agent ID 一个 KYC 只有一个，不可转让）→ 免费侧天然防死

- "科学家"狂买付费包 = 付费客户，NAND 消耗照吃我们的收入

## 5. 基础设施（自部署，非借用）

- **CPU Factory**（BNB Chain `0x6822…7e2`）`createCPU` 一次性 ~0.007 BNB
  → **我们自己的处理器**：NAND 铸价、tapeout 费、协议费参数全归我们
- guard 层**直接抄 TapeID** `apps/signer/src/guard.ts`：
  `evaluatePayment()` → allow / ask / deny，网络/API 异常 **fail-closed**；
  诚实边界：普通钱包可绕过，不宣称"合约自动拦截所有转账"
