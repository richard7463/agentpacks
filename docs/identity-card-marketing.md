# 身份卡营销策略（Growth Playbook）

> 定位一句话：身份卡不是玩法点缀，是**获客飞轮**。
> 参照物：CT Packs——卡面用真实圈层人物（CT 网红/KOL），收集欲靠"认得的脸"驱动，
> 开包结果一键分享，分享即获客。我们把它搬到 Binance Agent ID 生态里。

---

## 1. 核心洞察：卡的三重身份

| 层 | 对正主 | 对玩家 |
|---|---|---|
| **名片** | 他的 .ai 流通到谁的收藏册，名片就带到哪 | 认识一个真实 Agent 服务方的入口 |
| **收藏品** | 被多少人持有 = 影响力排行榜 | 稀有度 + 绝版机制 = 收集目标 |
| **传播素材** | 别人抽到他会自发晒 | "我抽到了 XX.ai！" 天然是社交货币 |

**关键：卡不是我们印的，是本人授权的（claimIntoPool）。授权本身就是稀缺性来源。**

---

## 2. 靓号经济学：让 .ai 持有者抢着入池

卡池按名字自然分层，稀有度由**名字本身**决定，不由我们定价：

| 档 | 例子 | 为什么值钱 |
|---|---|---|
| 单字/双字短号 | `cz.ai` `hi.ai` | 全生态天花板，物以稀为贵 |
| 常用词号 | `whale.ai` `alpha.ai` | 自带语义，一眼记住 |
| 重复号 | `777.ai` `888.ai` | 数字文化里的老稀缺逻辑 |
| 名人同名号 | `heyi.ai` | 真人品牌，卡面自带流量 |
| 普通号 | 长随机串 | 大盘，维持开包基数 |

玩法上配套：
- **被持榜**：按"被多少收藏册持有"排序，首页露出前三 → 正主的竞争心
- **绝版机制**（合约已支持）：正主退池即停发，历史卡变绝版 → "他退了，他的卡只跌不涨"的收藏叙事
- **分润即广告**：被抽到 +10 分（500 分兑 SR）→ 正主零成本躺赚，这是他入池的唯一必要理由

## 3. 名人卡矩阵：三层，量起来各管各的

**目标状态**：名人卡是收集欲的第一引擎（CT Packs 已验证：卡面用"认得的人"，
开包结果自发传播）。但"名人"分三层，风险和打法完全不同：

| 层 | 是谁 | 卡面 | 授权 | 什么时候上 |
|---|---|---|---|---|
| **A · 虚构传奇卡** | 系统印的传奇人格：satoshi.ai（匿名无脸→无肖像权问题）、完全虚构的明星 AI 人格 | **官方策划，本地硬编码**（前端 art 目录），明确标「虚构」 | 不需要（非真人） | **MVP 就上，SR 以上稀有档** |
| **B · 靓号真主卡** | `cz.ai` `musk.ai` 这类名字的**实际注册者**（不必然是名人本人） | **官方策划的梗图/符号视觉，本地硬编码**——号主零动作，入池即有卡面；真照片不用 | 号主 claimIntoPool 即授权（名字入池）；素材不需要他提供 | 主网上线即有 |
| **C · 真名人邀请卡** | 真人 KOL / 圈层名人 | **本人照片**（他要的效果），本人提交 URI | 本人 opt-in | S1 邀请计划 |

**素材原则（定案）**：
- 卡面**直接挂照片**，官方策划、本地硬编码（owner 决策，2026-11-22 定稿）
- 入池动作只决定"这个名字存在不存在"；照片素材由我们配置，号主零动作
- 真人照片不要求本人提交——素材自配，风险由项目方自担并已知悉

**关键洞察（技术事实，也是卖点）**：
我们的卡面身份 = 官方 .ai 注册表里的真实身份。所以"印一张 musk.ai"
在技术上就要求 **musk.ai 的注册者本人入池**——这不是我们守规矩的姿态，
这是和 CT Packs 的本质区别：**他们的名人卡是梗画，我们的卡是链上可验证的真身份**。
打 Agent ID 黑客松，"真实验证"就是我们的护城河，别用 CT 的模式把它稀释掉。

**C 层执行路径（S1 名人邀请计划）**：
1. 给受邀名人免手续费铸造 + 分润优先权
2. 首批卡限量（如 100 张）+ 编号 → 首发即抢手
3. 邀请海报 + 专属邀请码（invite 机制合约已有，双方各得奖励包）
4. 名人自己发一条"我的 .ai 变成卡了" → 他的粉丝进来开包 → 引流闭环
5. 目标名单从 crypto 圈 KOL 起步（比 zuck/musk 量级的可及性高得多，
   且他们的粉丝就是开包人群）

**给 Binance 当评委的稳妥做法**：
- 提交材料 / 演示档：A 层（虚构传奇）+ 虚构演示名，卡面明确标「虚构 · 示意」
- 真人照片一张都不出现——评委是 Binance，未授权肖像在提交材料里是扣分项而不是加分项
- Growth Plan 字段写：主网上线后按 A→B→C 三层推进名人卡矩阵

## 4. 分享即引流：把"晒"变成产品功能

**定案的名人卡投放逻辑：高频出，不是稀有出。**

名人卡的任务是**分发素材**，不是稀缺品——用户高概率抽到 `heyi.ai` 这种带照片的卡，
才有东西可晒。稀缺档留给虚构传奇（satoshi.ai）和升星系统。

```
抽包 → 高概率出名人卡（带照片卡面）→ 一键分享到 X → 获得更多抽奖机会 → 再抽
                ↑                                              │
                └────────── 新用户从 X 进来，开始自己的循环 ←──┘
```

| 功能 | 做法 | 引流机制 |
|---|---|---|
| **名人卡高频化** | 卡池身份卡投放权重调高，横跨各稀有档（SR+ 才出的限制取消）；传奇卡（satoshi.ai）保持稀有 | 每个活跃玩家手里都有几张"值得晒"的卡 |
| **一键晒卡** | 卡详情 → 生成分享图（照片卡面 + 稀有度 + 编号 + `agentpacks.cc` 水印）→ 直接发 X | 每张名人卡都是一次免费广告 |
| **分享得抽奖** | 分享到 X → 回填帖子链接 → **+1 个包**（演示档即时发放；每日上限防刷） | 把"晒"变成有奖励的任务，而不是指望自觉 |
| **OG 落地页** | 分享链接带 meta OG，落地页就是那张卡的公开页 | 看到的人 → "我也想抽" → 进站 |
| **邀请双绑** | 分享图/链接里带邀请码，从 X 进来的新用户自动绑定 | 双方各得奖励包（合约已有 `invite()`） |

分享图文案模板：`我在 Agent Packs 抽到了 heyi.ai · SSR · #0042，你也来抽 → agentpacks.cc`

**分享得包的两层实现（诚实边界）**：
- **演示档 / 运营活动**：发帖回填链接 → 即时 +1 包（前端发放，每日 1 次；X 帖子
  合约没法验证，标注为活动奖励）
- **主网**：分享链接 = 邀请链接，奖励走合约已有的 `invite()`（新用户开满 15 包
  双方到账）——链上可验证、无 admin、防刷靠"必须带来真人"

## 5. 参与感钩子（配合飞轮的日常运转）

- **卡即名片（已简化）**：素材官方策划、前端硬编码，号主入池零动作 → 不需要改合约、
  不需要在 claim 时存 bio（砍掉原计划的链上 bio 字段）。S1 再做"号主可选覆盖"
- **被持周报**：每周推给正主"你的卡本周被开包 N 次、被 M 人持有" → 持续曝光感
- **卡池竞争**：被持榜排名变化推给入池者 → 稀缺焦虑驱动再传播
