# Agent Packs · 电路卡视频生成提示词手册

> 用途：AI 视频工具（可灵 / 即梦 / Runway / Pika / Vidu）图生视频。
> 核心打法：**你已有的 12 张英雄立绘当首帧**（img2vid），风格零跑偏。
> 输出比例：X/抖音用 9:16 竖版，YouTube/落地页用 16:9；每个镜头 5~10 秒。

---

## 0 · 视频风格圣经

| 项 | 规定 |
|---|---|
| 世界 | 深墨紫电路空间 `#0F0C24`，地面是发光电路板走线，远处悬浮金色数据流 |
| 光 | 顶后方金色轮廓光为主，人物边缘带家族色 glow（青/红/金/紫） |
| 材质 | 全息镭射箔卡牌在场景中实体存在，会发光、会碎裂成数据粒子 |
| 镜头语言 | 电影感：慢推（push in）、环绕（orbit）、低角度仰拍英雄、高速冲刺跟拍 |
| 禁止 | 文字字幕（后期加）、水印、写实街景、白天外景、纸牌桌赌场感 ⚠️ |

**通用负面提示词**：
```
text, subtitles, watermark, logo, casino, poker table, realistic street, daytime,
chibi cartoon, extra limbs, morphing faces, flicker
```

## 3 · 工具参数速查

| 工具 | 推荐设置 |
|---|---|
| 可灵 Kling | 图生视频 → 首帧上传英雄图 → 提示词贴上表 → 5s/10s → 高品质模式；运动幅度不要拉满（防崩脸） |
| 即梦 | 图生视频 → 同上；中文提示词直接用 |
| Runway Gen-3 | 英雄图作 first frame，英文提示词，camera: slow push-in / orbit |
| Vidu/Pika | 参考"主体一致性"模式，垫同一张图生成全部镜头 |

**英文通用后缀**（英文工具贴这条）：
```
cinematic AI card game trailer, dark ink-purple circuit space #0F0C24, glowing circuit-board
floor, golden rim lighting, holographic foil particles, dramatic slow motion moment,
film quality, no text, no watermark
```

## 4 · 剪辑流水线（成片 30-60 秒）

```
镜头顺序建议（E 片）：E1→E2→E3→E4→E5→E6 → 接 A1→A3（开包+成型）→ 字幕收尾
音乐：史诗电子 + 鼓点渐强（ Epidemic 类 "epic hybrid trailer" 关键词）
后期字幕（视频内不生成，剪辑加）：
  0-3s   「你的 AI 会花钱。谁来守门？」
  中段   「12 种规则电路 · 流片在链上 · 谁也改不了」
  收尾   「agentid.cards · 每包必出名人卡」+ logo
节奏：每个镜头切在鼓点上；B4 的冲击瞬间给 0.5s 全屏白闪
```

## 5 · 合规红线（拍片也要守）

- 不出现赌场、扑克桌、老虎机意象——卡是"守门规则"不是"赌博筹码" ⚠️
- 不出现 Binance/币安 logo 或真人名人形象（名人卡镜头用 D 概念的"粒子抽象化"处理）
- 不提 token / 收益承诺；口号只讲"规则、验证、守门"
- hackathon 提交视频建议用 C 片（骗局拦截）——评委看的是产品价值
