# Agent Packs · 主宣传片《守门之夜》完整分镜

> 一支 50 秒叙事短片：一个反转结尾的故事，不是素材拼盘。
> 打法：12 张英雄立绘当图生视频首帧（可灵/即梦/Runway 均可），逐镜生成后按本表顺序剪辑。
> 比例：16:9 主版（落地页/YouTube）+ 9:16 竖版裁切（X/抖音）。

---

## 0 · 一句话故事

深夜，你的 AI 替你花钱——骗子混了进来，一张卡里的守门英雄苏醒，把黑暗拦下。
镜头拉远才发现：**刚才那场大战，就发生在你手里的一张卡牌里面。**

**三幕结构**：
```
第一幕（0-12s）世界：AI 在花钱，每笔都要过卡
第二幕（12-40s）危机：骗子潜入 → 警报 → 英雄苏醒拦下
第三幕（40-50s）反转+落版：战场缩回卡牌，卡牌落回卡包
```

## 1 · 完整分镜表（8 镜 · 每镜 5-8 秒）

### S1 · 世界（0-6s）｜首帧：暗场景图（无英雄）

```
深墨紫 #0F0C24 的无尽电路空间，中心悬浮一颗呼吸般明灭的金色光球（主人的钱袋），
细小的金色光点沿发光电路走线排成流动的队列，安静有序，景深处有缓慢移动的数据流。
镜头从高处缓缓下降推向光球。
```
运动：slow descent + push in｜字幕（后期加）：「深夜，你的 AI 还在花钱」

### S2 · 日常（6-12s）｜首帧：同场景，光点过闸

```
光点队列流经一道微微发光的半透明能量闸门，闸门上方悬浮一张模糊的全息卡牌虚影，
光点穿过闸门时逐一被青色光波"盖章"放行，节奏平稳如呼吸。
```
运动：横向平移跟拍队列｜字幕：「订阅、GPU、接口账单……每笔都要过卡」

### S3 · 潜入（12-18s）｜首帧：同场景，一枚异类

```
队尾混进一枚黑紫色的光点——表面伪装成微笑的友好光斑，但它拖出的影子却扭曲成
病毒触须的形状，缓慢蠕动着向闸门逼近，周围电路走线被它经过的地方微微黯淡。
```
运动：缓慢推近黑点（不安感）｜字幕：「然后，骗子来了」

### S4 · 警报（18-24s）｜首帧：黑点触碰闸门瞬间

```
黑点触碰闸门的刹那，空间炸响无声的红色警报：全场电路走线瞬间转红脉动，
光点四散躲避，光球剧烈收缩自我保护。音乐骤停，只剩低频轰鸣。
```
运动：快速 zoom out 展示全场变红｜无字幕，靠音效

### S5 · 苏醒 · 高潮①（24-32s）｜首帧：heroes/t8.jpg（落闸骑士）

```
闸门上方的卡牌虚影猛然实体化爆裂——落闸骑士从卡中砸落地面，塔盾插地的瞬间
升起一道巨大的红色能量闸墙，黑紫光点全力撞上盾面，迸发冲击波与火花，
慢动作：骑士纹丝不动，盔甲警示灯逐一点亮。
```
运动：天降+落地震屏，撞击瞬间 0.5s 慢动作

### S6 · 验证与斩碎 · 高潮②（32-40s）｜首帧：heroes/t2.jpg → heroes/t4.jpg

```
验证圣骑缓步上前，圆盾上的扫描之眼睁开，一道青色激光横扫黑点——
扫描光明确判定"非注册"，黑点的伪装微笑面具当场碎裂露出病毒真容；
紧接着居合剑客从侧面掠过，一道干净利落的青色斩击光痕，
病毒连同残影被斩成漫天无害的数据尘埃，缓缓飘散。
```
运动：t2 缓慢推近 → 斩击瞬间快速横摇｜两个镜头各 4s

### S7 · 恢复（40-46s）｜首帧：同场景，尘埃落定

```
尘埃飘散，全场电路从红色缓缓转回金青色，友好光点重新排起队通过重开的闸门，
光球恢复安稳的呼吸般明灭。卡牌虚影重新浮回闸门上方，一切如常。
```
运动：缓慢环绕（orbit）拉远｜字幕：「规则写死在链上 · 谁也改不了」

### S8 · 反转落版（46-52s）｜首帧：全场缩进卡牌

```
镜头开始急速持续拉远：整个战场、光球、闸门、英雄，全部缩进一枚悬浮的
全息镭射卡牌内部——卡牌在深墨紫空间中缓缓旋停，边缘金光流转；
随后卡牌轻轻落进一只金箔卡包，卡包合上，屏幕暗下只剩一句光字。
```
运动：rapid zoom out + 卡牌落包收尾
字幕落版：「你的 AI 会花钱。谁来守门？」→「agentid.cards · 每包必出名人卡」

## 2 · 生成与剪辑流水线

```
① 逐镜生成：8 个镜头 ×（可灵/即梦 图生视频，首帧按上表，5-8s，高品质模式）
② 剪辑顺序：S1→S2→S3→S4→S5→S6a→S6b→S7→S8，全片 ~50s
③ 音乐结构：氛围电子起（S1-S2）→ 骤停（S4）→ 战斗鼓点（S5-S6）→ 恢复和弦（S7）→ 落版重音（S8）
   搜索关键词：epic cinematic hybrid trailer / dark electronic build-up
④ 卡点：S4 警报踩在音乐骤停点；S5 落地踩重鼓；S8 拉远开始踩 cymbal swell
⑤ 字幕后期加（AI 不生成文字）：上方字幕表，白字 + 细金边，底部居中
⑥ 转场：S3→S4 硬切（惊吓点），其余 0.3s 叠化；S8 结尾黑场 1s 再出落版
```
