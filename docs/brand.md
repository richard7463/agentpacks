# 品牌定稿（2026-11-23）

## 大名
- **中文**：卡灵战争
- **英文**：Agent Packs
- **域名**：agentid.cards

## 核心设定（本体论）
每个卡灵**就是**一条链上规则的化身——不是"带着规则的英雄"，是规则本身。
抽到卡灵 = 收藏一条焊死在链上的 NAND 网表；穿上卡灵 = 让规则替你的 Agent 守门。

## Slogan
> 你抽到的不是英雄，是一条规则。
> AI 花钱，卡灵守门。
