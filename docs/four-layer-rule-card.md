# 四重电路规则卡（4-Layer Rule Card）设计定稿

> 模仿对象：tapeid.xyz 的四层资产架构。
> 一句话：**每张电路卡不是一张图，是四层各司其职的链上资产。**

## 1. 四重与 tapeid 的逐层对照

| 重 | 层 | tapeid 对应组件 | 我们的状态 | 规则卡上的样子 |
|---|---|---|---|---|
| **1 芯** | 电路层 | TapeOut processor 的 circuit NFT（45 门 agent-spend，NAND 逐门烧） | ✅ `tapeOut(cardId)` 已上合约（占位网表，流片前换真网表） | `circuit #7 · 11 门 NAND · 可转售` |
| **2 魂** | 参数层 | owner 签名卡（unitUsd / dailyBudgetUsd / payees，改参数不换电路） | ✅ 演示档已实现（`ovr`，数值用户自定（与稀有度无关）） | `每日 ≤ $20 · 上限内可调（调数值 → diff → 确认）` |
| **3 证** | 证书层 | rule certificate（卡面规则句 + 字节一致 + 64 采样 eval + owner 一致） | ✅ `ruleOf()` 链上可读；卡面印规则句 | `ruleOf(#42) → (0, 2800, 0) · 任何人可读` |
| **4 履** | 履历层 | TapeIDRecordRegistry（追加式 verdict 记录，permissionless 复算） | 🚧 checkPayment 可复算 ✅ / 守门人战绩 ✅ / 链上记录 = S1 | `checkPayment() 重放 ✓ · 守门 4 局` |

## 2. 电路复杂度档位（第 1 重的门数分级）

第 1 重的网表不是一种规格，按稀有度分四档（参考 tapeid agent-spend = 45 门深度 18）：

| 档 | 门数 | 深度 | 对应稀有度带 | 规则能力 |
|---|---|---|---|---|
| I | 3–8 | ≤4 | C / UC | 单维布尔：只查白名单、只查小额 |
| II | 10–20 | ≤8 | R / SR | 二维组合 + 人工旁路（剧场演示的 11 门即此档） |
| III | 25–45 | ≤18 | SSR / UR | 4-bit 额度步长 + 计数 + 冷却（agent-spend 同级） |
| IV | 45+ / latch | ≤24 | LR | 全维 + 状态（当日累计、重复扣款检测） |

**规则**：高稀有度卡 = 电路更深、参数档位更高——收集价值（稀有度）与实用价值（电路能力）同一条曲线。

## 3. 用户旅程（四重依次点亮）

```
抽卡          → 只有第 3 重（证书：卡面规则句，ruleOf 可读）
调数值        → 第 2 重亮（签名参数，档位内自由）
流片 tapeOut  → 第 1 重亮（circuit NFT 真身进钱包，可装备/转售）
守门/复算     → 第 4 重亮（guard 判定履历，任何人可重放）
```

免费玩家拿到的卡自带第 3 重（可玩可晒）；付费动作按层解锁——
经济模型的三重收入正好分别挂第 1 重（NAND）、转售（版税）、包（BNB）。
