# 四类电路卡（Four Circuit Families）设计定稿

> 每张电路卡属于四个家族之一。家族 = 这张卡**管什么**；
> 门数档位（four-layer-rule-card.md §2）= 这张卡的电路**有多深**。
> 两个维度正交：SSR 交易卡 = 深电路 + 交易语义。

## 1. 家族总表

| 家族 | 管 | 语义边界 | 守门人对应骗局 |
|---|---|---|---|
| **① 交易 Trade** | 额度：一天/一笔能花多少 | 止损（每日上限）、梭哈（单笔上限）、加仓（额度递增）、清仓（每日笔数） | 天价账单、套餐升级 |
| **② 风控 Lockdown** | 刹车：什么时候必须停 | 钻石手（笔间冷却）、**封控**（当日被骗后全锁 N 小时） | 重复扣款、连环诈骗 |
| **③ 安全 Security** | 对手方：钱能付给谁 | 白名单（只付 Agent ID）、杠杆（超半额需人工）、防仿冒（只付正主，身份卡） | 仿冒空投、陌生地址退款 |
| **④ 协作 Trust** | 签字的人：谁点头才算数 | **双签**（超半额需二人）、**会签**（N 中取 M）、**委托**（限时授权指定收款方） | 「紧急退款请立刻付」 |

## 2. 十二张卡全表（合约 ruleType 0..11）

| t | 卡 | 家族 | 规则 | 参数（mult = 100 + rarity×40 + star×20） |
|---|---|---|---|---|
| 0 | 止损 | 交易 | 每日支出上限 | `$20 × mult/100` |
| 1 | 梭哈 | 交易 | 单笔上限 | `$50 × mult/100` |
| 2 | 白名单 | 安全 | 只付持有 Agent ID 的地址 | 注册表 `balanceOf > 0` |
| 3 | 加仓 | 交易 | 当日额度随成功笔数增长 | `$30 起 +2%/笔` |
| 4 | 清仓 | 交易 | 每日笔数上限 | `3 + rarity/2 + star` |
| 5 | 抄底 | 交易 | 小额免人工 | `$5 × mult/100` 内直放 |
| 6 | 杠杆 | 安全 | 高额 + 人工闸门 | `$100 × mult/100`，超半额需人工 |
| 7 | 钻石手 | 风控 | 两笔支付冷却 | `3600 - rarity×300 - star×120` 秒 |
| **8** | 封控 | **风控** | 当日一旦被骗，剩余时间全锁 | 锁 `2 小时 × mult/100` |
| **9** | 双签 | **协作** | 超半额需两人批准 | 基准 `$50 × mult/100` |

## 3. 扩展性：新卡种怎么长（一个处理器，N 条电路）

**永远只有一个自部署处理器**。新规则卡 = 在同一处理器上多流片一条网表（几十门 NAND，几美分），之后该类所有卡共享这条电路。

| 方式 | 怎么加 | 适合 |
|---|---|---|
| **A 部署期扩容** | `HOUSE_NETLIST` 用动态 `bytes[]`（替换定长 `[8]`），构造时写入 12+ 种 | 本轮 12 种 |
| **B 赛季合约** | S1 新卡种发新合约（同处理器流片、新卡池），老合约零改动 | 赛季上新 |
| **C 玩家自定义** | `tapeOutCustom(cardId, circuitId)`：社区用 TapeForge 造电路 → 流片 → 绑卡 | 规则长尾，permissionless |

三条路径都不引入 setter / admin；合约 v2 落实 A，B/C 进 S1 排期。

## 4. 合约 v2 变更清单（下一轮实现）

- `HOUSE_CARDS 8 → 12`，`ruleOf` 分支 + 4
- `checkPayment` 增参：`uint8 approvals`（已批准人数）与 `bool trippedToday`（当日是否已被骗）
  - 未部署即可自由改 ABI；演示档前端同步
- t8 封控：`trippedToday → 拒绝`，解锁时间 = p1
- t9 双签：`amount ≤ p1/2` 直放；`≤ p1` 需 `approvals ≥ 2`；`> p1` 拒
- t10 会签：`amount > p1` 需 `approvals ≥ M`（M = 2 + star/2）
- t11 委托：`payee ∈ 名单 ∧ now ≤ 窗口` 才放行
- 测试：四类各至少 1 分支 + tripped/approvals 边界

## 5. 网表档位随家族配重（供 TapeForge 编译）

| 家族 | 门数重心 | 原因 |
|---|---|---|
| 交易 | 中（I–III） | 额度比较、计数 |
| 风控 | 深（III–IV，含 latch 状态） | 封控需要"当日已被骗"记忆位 |
| 安全 | 中（II–III） | 名单/注册表位查询 |
| 协作 | 浅–中（I–II，M 路输入） | 会签 = 多输入多数门（tapeid MAJ3 同款） |
