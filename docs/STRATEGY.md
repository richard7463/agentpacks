## 1. 硬约束：一队一项目 → 三项目 = 三支独立队伍

三个项目不能以同一队伍身份重复提交。操作原则：

1. **队伍身份彻底分开**：不同提交人/团队名、不同提交表单、各自独立的项目描述与联系渠道。
2. **绝不脚本化互刷**：公告明确"恶意刷量、非法批量注册账户用于交互"直接取消资格。三项目之间可以有真实的交叉体验（黑客松参赛者本来就人手一个 Agent ID，互相体验对方项目是常态），但：
   - 不要同一批钱包在三项目里机械地全量交互；
   - 不要用批量注册的 KYC 账号刷 30 地址门槛；
   - 每个项目要建**自己的有机漏斗**（见 §4）。
3. **同一项目只能拿一个奖** → 每个项目按自己最强的奖项路径设计（见 §2），别两头摇摆。

## 4. ≥30 个 Agent ID 地址：共享增长原则（有机，防刷量判定）

每个项目 30 个 Agent ID 地址是**硬门槛**（创新奖资格）也是领航奖排名的核心指标。策略：

- **基础盘（约 15–20 个）**：黑客松参赛者与 Binance 钱包社区成员本身 100% 持有 Agent ID。渠道：官方活动评论区/Telegram/Discord、BNB Chain 与 Binance 钱包 X 帖的跟评、黑客松参赛者互访。给他们**真实可玩的东西**（WORM：绑一个家族、看它生老病死；Stave：免费刻一块 Tier I 石头），一次交互即计入。
- **叙事盘（约 10–15 个）**：WORM 的 Anthropic 论文角度可触达 AI 安全/加密记者与 KOL；Stave 的"agent 替你打工赚 NFT"可触达 AI Agent 圈。一篇爆帖顶 30 个地址。
- **转化设计**：首次交互必须 **≤1 笔交易 + ≤0.001 BNB 成本**。WORM 绑定费 0.0005 BNB；Stave carve 免费只付 gas。
- **社区传播奖是杠杆**：鼓励用户为你的项目发 X 帖（#BinanceWalletHackathon #AgenticWallet），他们有机会分 2,000 USDC——把你的增长变成他们的中奖机会。

## 5. 九条安全红线 · 三项目通用对照表

| # | 红线 | 通用对策 |
|---|---|---|
| 1 | 不支持网页扫码登录 Agentic Wallet / 不存会话 | 站点纯前端钱包直连或 App 内访问；零扫码、零配对码 |
| 2 | Skill 不得含绕过用户确认的提示词 | 所有资产操作必须用户亲眼确认；skill 文案显式声明 |
| 3 | 不无感转走资产 / 不索无限授权 | 不用 approve/permit；支付金额用户可见且即时销毁或进合约固定逻辑 |
| 4 | 合约开源 + **披露 owner 权限** | 三合约全部无 owner/无增发/无暂停/无提款；README 与 BscScan 注释明示 |
| 5 | 不冒用币安品牌 | 名字/域名/文案零 Binance/币安/BNB 冒充；引用论文与 CZ 公开发言注明出处 |
| 6 | 不收集助记词/私钥/API Secret/配对码 | 零收集，纯链上交互 |
| 7 | 不承诺收益 | 全部 utility/体验措辞；WORM 的 $AIWORM 若为代币**绝不能带收益承诺**（建议黑客松期仅作为积分/纪念物展示） |
| 8 | 交易页面风险提示 | 页脚统一风险声明 |
| 9 | Agent ID 不做成"按名查别人钱包"工具 | 只做准入/署名/角色，不做反查 |

> 红线 4 的"披露"是提交材料里必须写的段落，不是可选项。

## 7. 新增项目档案（TapeGit / Agent Packs）

> 2026-11-21 与 Grok 会话产出两个新概念，档案与判研如下。

### Agent Packs（`hackathon/agentpacks/`）— 领航奖最佳适配体
- **定位**：CT 卡包（已验证的开包/自走棋爽感）× Binance Agent ID（卡=真实身份）× TapeOut 电路（卡魂=链上 NFT）+ 人人造卡分润（S1）。
- **自家协同（升级）**：卡魂沿用**自家 tapeid.xyz** 的规则电路模型（AI 名字+规则电路一笔原子铸造，测试网已上线）——Agent Packs 成为 TapeID 的消费分发层：玩家开包接触"规则电路"，equip 穿到自己 .ai 身上；两个项目互相导流，且给 Packs 补上了"真有用"的一环（行为模组，不只是收藏）。
- **为什么适合领航奖**：**每日免费包 = 每个 .ai 用户每天一笔便宜交易**——交互地址数 × 回访天数，正是领航奖加权指标的最优解；邀请裂变 + 付费包再叠交易额。全项目组合里**唯一自带留存引擎**的一个。
- **代价**：也是工程量最大的一个（合约+游戏前端），18 天内必须砍成 Season 0 四件套（开包/每日领取/认领/自走棋 lite），赌场与造卡全部后置。
- **材料就绪**：`pitch.html`（卡牌视觉，已可开）+ `DEVELOPMENT.md`（合约草图/概率表/排期/§9 tapeid 协同）+ `HACKATHON_CHECKLIST.md`。

### TapeGit（生态长线项目，不建议本届参赛）
- **定位**：电路的 GitHub——人和 AI 用 Git 工作流协作设计电路，成熟后流片成 TapeOut 不可变 Circuit NFT；名字未占用，生态卡位空白（TapeOut 管流片、TapeAI 管规则、TapeGit 管协作）。
- **判断**：好名字、真空位，但 18 天内做不出可体验的 MVP，且需与 TapeOut/TapeAI 生态深度兼容。**留作 12 月后的生态项目**，别挤占本届（一队一项目 + 精力有限）。
