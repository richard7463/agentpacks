# 卡灵战争 · 官方世界观（Story Bible）

> 记录于 2026-11-23，品牌定稿配套。所有 pitch、官宣、视频、文案从这里取词。

## 序章 · AI 替人类花钱的时代

每个 Binance Agent ID 用户，都有一群替他花钱的 AI：付订阅、买算力、结算接口、支付服务。
深夜的链上，无数笔付款像光点一样流动——**这是 AI 替人类掌管金库的第一个时代。**

## 黑暗降临 · 四类骗局向 Agent 扑来

光点的队伍里混进了黑暗：

- **仿冒者**——名字只差一个字母的假 .ai（`kestre1.ai`）
- **重复扣款**——同一收款方一分钟内再偷一次
- **天价"紧急退款"**——陌生地址 + 催你快付
- **越权"自动升级"**——真服务商，金额却是平时的十倍

没有防备的 Agent，一觉醒来金库被掏空。

## 战争爆发 · 卡灵为 Agent ID 用户而战

人类需要能替 AI 拔刀的存在。于是**卡灵**诞生了——

**每张卡灵，就是一条焊死在链上的 NAND 电路规则的化身。**
他不是"带着规则的英雄，他**就是**规则：守账武士就是止损、落闸骑士就是封控、验证圣骑就是白名单。

四大阵营、十二卡灵，只为一个使命而战：

> **保护 Binance Agent ID 用户的每一笔付款。**

## 战线设定

| 世界观 | 游戏机制 |
|---|---|
| 只有**真人认证**的身份才能召唤卡灵 | Agent ID = 门票（合约 KYC 墙） |
| 每笔付款 = 一次遭遇战 | checkPayment / 守门之战 |
| 卡灵真身铸成 = 流片 | tapeOut（NAND 逐门烧） |
| 黑暗永不消失，只是被一次次拦下 | 10 笔请求、S/A/B 评级 |
| 断网时刻，卡灵宁死不放进黑暗 | fail-closed：宁拒不猜 |
| 战季轮回，新卡灵参战 | 赛季 = 战季（S1：《卡灵远征》） |
| 名人卡灵降临，人类并肩作战 | 名人卡 · 照片上卡 · 分享得包 |

## 第 0 战季 · 现在

战争刚刚开始。第一批卡灵已就位，第一场守门之战正在实验室打响：
**你的 AI 会花钱，卡灵替你守门。**
