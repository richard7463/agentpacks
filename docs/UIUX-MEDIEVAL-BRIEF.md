# 卡灵战争 · UI/UX 风格 Brief（交接给下一位模型）

## 0. 一句话目标
把现在的「赛博霓虹卡牌游戏」重做成 **中世纪暗黑奇幻 / 战士遗迹** 风格：
像《暗黑破坏神》《杀戮尖塔》《万智牌》的暗金羊皮纸质感，而不是现在的荧光青紫。

中文名 **卡灵战争**，英文 **Kaling War / Agent Packs**。叙事：每张卡是一条焊死在链上的 NAND 守门规则，卡是"武器"，电路是"灵魂"。

## 1. 视觉语言
### 配色（替换现有霓虹色）
- 背景：黑曜石 `#0B0913` / 深石 `#151222`
- 主色：古金 `#C9A227`、暗金 `#8A6D1F`
- 文字：羊皮纸 `#E8DCC0`、旧纸 `#C7B899`
- 强调：血红 `#8B1E2D`、钢青 `#7A8B99`、苔绿 `#4E6B4A`
- 稀有度用**材质**表达，而不是霓虹色：
  - 普通 = 粗铁 / 精良 = 抛光钢 / 稀有 = 青铜 / 史诗 = 秘银
  - 传说 = 黄金 / 神话 = 龙鳞金 / 至尊 = 龙骨+符文

### 字体
- 标题/数字：衬线体（Noto Serif SC / Cinzel / Trajan 风格），字重 700–900
- 正文：Noto Sans SC，字号不要太小
- 目前用的 Oswald + Noto Sans SC 可以保留 Sans 部分，但标题必须换衬线

### 质感
- 卡框：双层金属边框 + 铆钉 + 角饰 + 羊皮纸底
- 面板：石碑 / 羊皮纸 / 铁板，带划痕与边缘磨损
- 按钮：雕刻金属牌（不是胶囊形霓虹按钮）
- 图标：剑、盾、锁、天平、卷轴、龙、盔甲，替代现在的几何符号

## 2. 各模块改造方向
- **登录/落地**：古地图 + 骑士剪影 + 火把微光；标题用大衬线金字
- **卡包**：封蜡信封 / 皮革包，撕开 = 蜡封碎裂 + 羊皮纸展开（保留现有 WebGL 镭射层但可以改成金属光泽）
- **卡面**：人物肖像保持，外框换成金属浮雕；稀有度角标换成宝石/纹章
- **收藏页**：像军械库 / 卡册，按稀有度分栏（铁/钢/银/金/龙）
- **规则证书**：改成"卷轴 / 铭文石板"样式，不要现在的代码框
- **实验室**：炼金台 / 锻造炉风格
- **我的**：骑士档案 + 战利品清单
- **Agent Skill / 演示页**：古书页 + 传令卷轴，但保留技术信息可读性

## 3. 动效与声音
- 开包：蜡封撕裂 → 羊皮纸展开 → 卡片逐张"拔出"，高稀有度加剑出鞘声
- 声音：**保留当前 WebAudio 合成器结构**（`app.js` 里的 `SFX` / `tone` / `noise` / `chord`），只把音色改成：金属碰撞、羊皮纸摩擦、号角、铁剑出鞘、低沉鼓点。不要引入外部音频文件。
- 粒子：保留 `fx.js` 的 canvas 粒子（burst / converge），颜色改成金/火星/铁屑。
- 减少动效偏好 `prefers-reduced-motion` 必须继续尊重。

## 4. 硬约束（不要动）
- 所有 DOM id / class / 函数签名保持不变（Skill 和文档依赖它们）
- 合约地址、ABI、Skill 端点不许改
- 不新增 npm 依赖；纯 HTML/CSS/JS
- 移动端可用；导航栏最后 `Agent ▾` 菜单保留
- 中文稀有度名称：`普通 / 精良 / 稀有 / 史诗 / 传说 / 神话 / 至尊`
- 「不构成链上强制拦截」这句诚实边界必须在演示页保留
- 不出现「积分 / 第 0 战季」概念

## 5. 需要改的主要文件
- `ui.css` —— 90% 的视觉改造在这里（颜色变量、卡框、按钮、面板、动效）
- `fx.js` —— 粒子颜色/形状、开包动效节奏、声音调用
- `app.js` —— `SFX` 音色、卡面 HTML 结构（`cardHTML` / `heroHTML` / `faceHTML`）、少量文案
- `index.html` —— 落地页文案、图标、结构微调
- `skill.html` / `agent-wallet.html` / `demo.html` —— 同风格统一
- 不要改 `contracts/`、`api/`、`skills/`（除非同步文档）

## 6. 验收标准
1. 打开首页第一眼是暗金羊皮纸 + 中世纪战士气质，没有荧光青紫
2. 七档稀有度靠**材质**就能区分，不靠颜色标签
3. 开包动效/声音有"撕蜡封 → 拔剑出卡"的感觉，且和现在一样顺滑
4. 所有现有交互（开包、翻卡、流片、我的、Agent 菜单）不回归
5. 手机上可用
6. `forge test` 仍然 76/76
