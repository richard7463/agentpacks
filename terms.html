服务条款与免责声明

最后更新：2026 年 11 月 23 日

一句话：这是一个链上卡牌实验。卡是规则，不是投资品；包是内容，不是彩票；我们不发行代币，也不承诺任何收益。

1. 服务性质

卡灵战争（Agent Packs）是一套部署在 BNB Smart Chain 上的开源智能合约与前端界面。卡牌是链上 NFT，其"规则"由公开的 NAND 网表定义，任何人可读取、复算、验证。

本项目参与 Binance Agent ID Hackathon，属于技术演示与社区实验，不构成任何形式的金融服务、投资服务、支付服务或博彩服务。

2. 不发行代币

本项目不发行任何代币，不进行代币销售、代币空投或代币质押。站内出现的"积分（packPoints）"仅为链上记账的进度值，不可转让、不可兑换、不具有任何货币价值。

3. 卡包与随机性

卡包内容通过链上 commit-reveal 机制产生：购买后先提交承诺，等待一个区块后揭示。结果可被任何人复算。

  • 卡包属于内容消费，不属于彩票、抽奖或有价证券。
  • 我们不保证任何卡牌的二级市场价值或流动性。
  • 概率公示在站内，合约逻辑公开可查。

4. 费用

购买卡包、流片（tapeOut）等操作需要支付 BNB 网络费用与合约内定价。所有价格以合约实时读取为准。链上交易一旦确认不可撤销。

5. 身份与隐私

本服务通过 Binance Agent ID 注册表校验地址是否持有 .ai 身份。我们不会要求你提交姓名、证件、住址或任何链下身份信息。卡池为自愿认领（opt-in），退出后已发出的卡成为绝版。

6. 名人卡说明

名人卡使用公开可查的肖像素材，来源与授权记录见仓库 faces/CREDITS.txt。名人卡仅用于表达"某条规则的人格化"，不代表相关人士对本项目的背书、合作或推荐。若权利人提出异议，我们将下架对应素材。

  • 智能合约可能存在未知漏洞，尽管我们已进行测试与审计式复查。
  • 区块链网络可能拥堵、分叉或出现异常，导致交易延迟或失败。
  • 卡牌价格与流动性可能归零。
  • 规则电路是"判定工具"，不构成法律、税务或投资建议；最终付款责任始终由人类承担。

8. 责任限制
